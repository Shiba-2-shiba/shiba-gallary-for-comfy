# Gallery Implementation Plan

> For agentic workers: use executing-plans or subagent-driven-development task-by-task.

**Goal:** Implement the approved fast, read-only ComfyUI gallery and parameter comparison.
**Architecture:** Independent Vue application in an isolated overlay, registered through ComfyUI's public extension API. Python aiohttp routes serve confined output folders, versioned thumbnails and saved metadata. No internal frontend state access.
**Tech Stack:** Vue 3, TypeScript, Vite; Python/Pillow/aiohttp.
**Spec:** ../specs/gallery-spec.md (actual path: docs/specs/gallery-spec.md)

## Global Constraints
- No image deletion or workflow rewriting. All image routes are read-only.
- Left reference stays fixed, newest-first folder view, checks reset on close.
- Missing values never become equal values. Prompt differences excluded only when identified.
- All caches are temporary. API namespace /shiba-gallery avoids upstream collisions.
- No user image or metadata is sent outside ComfyUI.
- Vue selection is an implementation decision, not a prior user commitment. Keep dependencies small.

## Review Focus
- Symlinks and traversal cannot escape output directory.
- Overwrites invalidate thumbnails and stale responses cannot change selected image.
- Metadata absence, damaged JSON and source disagreement remain explicit.
- Close/reopen/folder switches clear appropriate state and abort stale updates.
- Same-type nodes never silently match by position without showing uncertainty.

## Execution rulings
- Vue 3 was selected as a builder decision after the user authorized implementation; the old React code was not copied.
- Public extension-boundary and proxy-path behavior were tested with a synthetic host; no actual latest-ComfyUI compatibility claim.
- Native Windows handles implemented; Windows tests deferred to CI.
- Seed omitted from identifiable normalized display/differences after later user instruction; raw values retained.
- Browser E2E blocked at browser startup by environment; bundled smoke and DOM-component tests are not substituted as an E2E pass.
